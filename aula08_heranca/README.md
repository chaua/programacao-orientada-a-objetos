# Aula 08 — Herança simples: contas bancárias

Esta aula apresenta herança usando uma classe mãe `Conta` e três classes filhas: `ContaCorrente`, `ContaPoupanca` e `ContaSalario`.

Conceitos trabalhados:

- `extends`
- reaproveitamento de atributos e métodos
- `super`
- sobrescrita com `@override`
- especialização de regras em classes filhas

Exercício sugerido:

1. Crie uma nova classe `ContaInvestimento` que herde de `Conta`.
2. Faça a conta investimento cobrar uma tarifa mensal de R$ 20,00.
3. Crie um método `aplicarRendimento()` com uma taxa escolhida por você.
4. Teste a nova classe no `main.dart`.
