# Aula 10 — Classes abstratas: polígonos

Esta aula apresenta classe abstrata usando figuras geométricas simples.

A classe `Poligono` é abstrata e funciona como modelo. As classes `Triangulo`, `Quadrado` e `Pentagono` herdam de `Poligono` e implementam seus próprios comportamentos.

Conceitos trabalhados:

- `abstract class`
- método abstrato
- getter abstrato
- método concreto herdado
- `extends`
- `@override`

Exercício sugerido:

1. Crie uma classe `Hexagono`.
2. Faça `Hexagono` herdar de `Poligono`.
3. Defina `numeroDeLados` como 6.
4. Crie um desenho simples usando `print()`.
5. Adicione `Hexagono()` na lista do `main.dart`.
