
Caso uso
========

Agenda de telefones
    - Registrar telefones
    - Listar telefones
    - Editar telefone
    - Excluir telefone


1) Para cada caso de uso

1.1) Identificar as entidades

    Contato(nome, telefone)

1.2) Para cada interação do ator com o caso de uso, criamos uma classe View

    ContatoView
        - Registrar
        - Listar
        - Atualizar
        - Excluir 

1.3) Cria um controlador para cada caso de uso 
    
    ContatoController
